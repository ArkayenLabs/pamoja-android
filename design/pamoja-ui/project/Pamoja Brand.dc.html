Brand palette build

Three screens, rebuilt on the official indigo system. Indigo is the only interactive colour — buttons, active tabs, the "you" row. Teal means progress and success, amber means streak and medal. Surfaces stay neutral so those three signals never have to compete with decoration.

Type is Sora for display and every number — geometric, slightly narrow, so a six-figure step count still fits inside the ring — with Manrope for UI text and DM Mono for wide-tracked labels. Shape language is soft-square: 26px cards, 20px buttons, 15px icon tiles, circles reserved for people. Depth in dark theme comes from the layered surface tiers plus a 3.5% top highlight, never from black.
